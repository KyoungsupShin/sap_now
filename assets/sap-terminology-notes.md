# Terminology editing

설명과 업무 사례는 한국어로 유지하고 SAP 제품명 및 개념·기능 라벨은 영어로 표기한다.

- SAP 제품: Joule, SAP AI Core, SAP AI Launchpad, SAP BTP cockpit.
- 개념·기능: Autonomous Enterprise, Business Context, Knowledge Graph, Orchestration, Governance, Runtime, Authorization, Human Oversight, Guardrails.
- A2A는 Agent 간 협업을 위한 용어이며 별도의 Agent 제품이 아니다.
- Harness Assistant와 Deep Agent는 이 발표의 구성 요소·역할 명칭이며 SAP 공식 제품명이라는 의미가 아니다.

기존 한국어 편집 메모의 전면 한글 라벨보다 이 기준을 우선한다. 이미지와 SAP 공식 템플릿은 유지하며 4페이지 라벨에 맞춰 5페이지의 축소 이미지를 갱신한다.

추가 통일: 자율형 기업 → Autonomous Enterprise, 자율형 업무 → Autonomous Operations, 업무 문맥/맥락 → Business Context, 온톨로지 → Ontology, 컴플라이언스 → Compliance, 전문 Agent → Specialist Agent. 비즈니스 용어 Lead Time, Demand Forecast, Production Capacity도 영어로 표기한다.

외래어도 영어 표기로 통일한다: 앱 → App, 프로세스 → Process, 데이터 → Data, 플랫폼 → Platform, 시스템 → System, 서비스 → Service, 비즈니스 → Business, 시나리오 → Scenario, 데모 → Demo, 인터페이스 → Interface, 프롬프트 → Prompt, 모니터링 → Monitoring, 리더십 → Leadership, 루틴 → Routine, 리스크 → Risk, 미팅 → Meeting, 이벤트 → Event, 테스트 → Test, 인프라 → Infrastructure, 로그 → Log, 로직 → Logic, 오더 → Order, 모델 → Model, 버전 → Version, 섹션 → Section, 비전 → Vision, 모드 → Mode, 팀 → Team. 한국어 문장과 업무 설명은 유지한다. 원본 PDF에서 추출한 이미지 안의 텍스트는 원본 그대로 보존한다.

전체 29페이지 편집 점검: Presentation Agenda, Business Operating Model, Business Challenges, Key Capabilities, Business Outcomes 및 기술·기능 라벨을 영어로 정리. AI-Native 비교에는 원본 SAP 자료의 Software that Does, Landscape Boundary, System of Context를 사용. 일반 업무 설명은 한국어로 유지.
