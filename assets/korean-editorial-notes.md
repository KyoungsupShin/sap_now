# 한국어 중심 발표 편집

29장의 순서와 파일명, SAP PDF 원본 그림은 유지했다. 한국어 청취자를 위해 제목, 설명, 목차, 섹션명, 실행 단계와 Agent 역할을 한국어로 바꾸고 제품명과 핵심 용어(Agent, AI-Native, Joule, Harness, Deep Agent, SAP BTP, A2A 등)는 유지했다. PDF 그림 내부의 영문은 원본 보존을 위해 수정하지 않았다.

출처 표시, 반복 Advisory 푸터, 편집용 다음 페이지 힌트와 중복 소제목은 발표 화면에서 제거했다. 출처 PDF 페이지, 이미지 추출 방식, 원본 해시와 원본 INTERNAL / CONFIDENTIAL 표시는 sap-pdf-image-sources.json, draft-visual-sources.md, deck-flow-notes.md에 남아 있다. 원본 자료의 분류나 권리를 변경한 것으로 해석하지 않는다.

문맥, 실행 흐름, 실행 루프, 사람의 통제, 거버넌스 페이지의 반복 하단 요약은 제거했다. 실행 루프의 담당자 전달 조건은 본문에 남겼다. AI-Native 비교의 반복 결론과 BTP 비교의 일률적인 TCO / OPEX 부등식도 제거했다. 마지막 비즈니스 가치 페이지는 성과 목록이 내용의 일부이므로 유지했다. 팀 페이지는 여섯 축소 이미지와 제목으로 공통 기반을 설명하므로 반복 영문 팀명과 하단 공통 기반 문구를 제거했다.
